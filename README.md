\# Restaurant Review Management System



A menu-driven restaurant review management system developed in C using a singly linked list.



\## Features



\- Add restaurant reviews at the head or tail of the linked list.

\- Search for restaurants by name, address, or rating.

\- Update restaurant information, including name, address, rating, average meal cost, and delivery availability.

\- Delete restaurant reviews by name, address, or rating.

\- Filter restaurants by rating, meal cost, and delivery availability.

\- Calculate the total number of reviews and overall average meal cost.



\## Technical Concepts



\- C programming

\- Structures (`struct`)

\- Singly linked lists

\- Pointers and dynamic memory allocation

\- Searching, insertion, and deletion

\- Input validation and memory management



\## Compilation and Execution



Compile using GCC:



```bash

gcc -std=c11 -Wall -Wextra -Wpedantic Restaurant\_Review\_LinkedList.c -o restaurant

```



Run the program:



```bash

./restaurant

```



On Windows PowerShell:



```powershell

.\\restaurant.exe

```



\## Limitations



\- Restaurant reviews are stored in memory and are not saved after the program exits.

\- The program runs through a command-line interface.
